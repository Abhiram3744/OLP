# PrepForge MERN

Full-stack account signup starter using React, Express, MongoDB, and Node.js.

## Setup

1. Copy `server/.env.example` to `server/.env` and set `MONGODB_URI`.
2. Install everything: `npm run install:all`
3. Start the client and API together: `npm run dev`

The React app runs at `http://localhost:5173` and the API at `http://localhost:5000`.
